# CodexBar Implementation Plan

> **面向智能体执行者：** REQUIRED SUB-SKILL：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施本计划。所有步骤使用复选框跟踪。

**目标：** 构建一个原生 macOS 菜单栏应用，实时显示 Codex 五小时与每周额度的剩余百分比。

**架构：** SwiftUI `MenuBarExtra` 负责展示，独立的 App Server 客户端通过 stdio JSON-RPC 调用本机 `codex app-server`。领域解析器将官方 `usedPercent` 转成剩余量，视图模型负责缓存、刷新、重连和颜色状态，`SMAppService` 负责登录启动。

**技术栈：** Swift 6、SwiftUI、Foundation `Process`/`Pipe`、ServiceManagement、Swift Package Manager、XCTest。

**规格：** `docs/superpowers/specs/2026-09-07-codex-bar-design.md`

## 全局约束

- 目标设备为 Apple M1 Pro、macOS 26.5；Swift Package 最低平台设为 macOS 14。
- 数据源固定为已安装的 `/opt/homebrew/bin/codex`（当前版本 `codex-cli 0.147.0`），并保留 PATH 和常见路径探测作为回退。
- 菜单栏文案固定为 `5h <百分比>% · 周 <百分比>%`。
- 剩余量 `>= 50%` 为绿色、`20...49%` 为橙色、`< 20%` 为红色；缺失或陈旧数据为灰色警告态。
- 每 60 秒主动刷新，并处理 `account/rateLimits/updated`；失败时保留最后一次成功值。
- 不读取凭据文件，不记录 Token，不调用私有 Web 接口，不保存历史用量。
- 当前目录没有 Git 元数据；开始实施时先初始化本项目 Git，之后按任务提交。

```swift
struct RateLimitWindowDTO: Codable, Equatable, Sendable {
    let usedPercent: Int
    let windowDurationMins: Int?
    let resetsAt: Int?
}

struct RateLimitSnapshotDTO: Codable, Equatable, Sendable {
    let limitId: String?
    let primary: RateLimitWindowDTO?
    let secondary: RateLimitWindowDTO?
}

struct RateLimitsResponse: Codable, Equatable, Sendable {
    let rateLimits: RateLimitSnapshotDTO
    let rateLimitsByLimitId: [String: RateLimitSnapshotDTO]?
}

struct UsageWindow: Codable, Equatable, Sendable {
    let remainingPercent: Int
    let resetsAt: Date?
    static func remaining(fromUsed used: Int) -> Int { min(100, max(0, 100 - used)) }
}

enum UsageLevel: Equatable, Sendable {
    case healthy, warning, critical, stale
    static func level(forRemaining value: Int) -> Self {
        value >= 50 ? .healthy : value >= 20 ? .warning : .critical
    }
}
```

同一测试文件提供线程安全替身，避免依赖真实进程：

```swift
final class FakeRPCTransport: RPCTransport, @unchecked Sendable {
    private let lock = NSLock()
    private var onLine: (@Sendable (Data) -> Void)?
    private var writes: [Data] = []

    var lastWrittenMethod: String? {
        lock.withLock {
            guard let data = writes.last,
                  let object = try? JSONSerialization.jsonObject(with: data) as? [String: Any]
            else { return nil }
            return object["method"] as? String
        }
    }

    func start(onLine: @escaping @Sendable (Data) -> Void,
               onTermination: @escaping @Sendable (Int32) -> Void) async throws {
        lock.withLock { self.onLine = onLine }
    }

    func write(_ data: Data) async throws { lock.withLock { writes.append(data) } }
    func stop() async {}
    func emit(_ line: String) { lock.withLock { onLine }?(Data(line.utf8)) }
}
```

- [ ] **步骤 3：实现 JSON 值、请求编号和逐行收发**

```swift
enum JSONValue: Codable, Equatable, Sendable {
    case object([String: JSONValue]), array([JSONValue]), string(String)
    case number(Double), bool(Bool), null

    subscript(_ key: String) -> JSONValue? {
        guard case let .object(value) = self else { return nil }
        return value[key]
    }

    init(from decoder: Decoder) throws {
        let box = try decoder.singleValueContainer()
        if box.decodeNil() { self = .null }
        else if let value = try? box.decode(Bool.self) { self = .bool(value) }
        else if let value = try? box.decode(Double.self) { self = .number(value) }
        else if let value = try? box.decode(String.self) { self = .string(value) }
        else if let value = try? box.decode([JSONValue].self) { self = .array(value) }
        else { self = .object(try box.decode([String: JSONValue].self)) }
    }

    func encode(to encoder: Encoder) throws {
        var box = encoder.singleValueContainer()
        switch self {
        case let .object(value): try box.encode(value)
        case let .array(value): try box.encode(value)
        case let .string(value): try box.encode(value)
        case let .number(value): try box.encode(value)
        case let .bool(value): try box.encode(value)
        case .null: try box.encodeNil()
        }
    }
}

protocol RPCConnecting: Sendable {
    func start() async throws
    func request(method: String, params: JSONValue?) async throws -> JSONValue
    func notify(method: String, params: JSONValue?) async throws
    func stop() async
}

protocol RPCTransport: Sendable {
    func start(
        onLine: @escaping @Sendable (Data) -> Void,
        onTermination: @escaping @Sendable (Int32) -> Void
    ) async throws
    func write(_ data: Data) async throws
    func stop() async
}
```

`JSONRPCConnection` 使用递增整数 ID 保存待完成 continuation；收到 `id/result` 时恢复对应请求，收到 `method/params` 时调用通知闭包，收到 `error` 时抛出包含 code/message 的 `JSONRPCError.remote`。每次写入必须追加单个换行符。

enum TestFailure: Error { case offline }

final class FakeUsageProvider: CodexUsageProviding, @unchecked Sendable {
    private let lock = NSLock()
    var results: [Result<RateLimitsResponse, Error>]
    init(results: [Result<RateLimitsResponse, Error>]) { self.results = results }
    func connect() async throws {}
    func fetchRateLimits() async throws -> RateLimitsResponse {
        try lock.withLock { try results.removeFirst().get() }
    }
    func updates() -> AsyncStream<RateLimitsResponse> { AsyncStream { $0.finish() } }
    func stop() async {}
}

    var snapshot: UsageSnapshot?
    func load() -> UsageSnapshot? { snapshot }
    func save(_ value: UsageSnapshot) { snapshot = value }

- [ ] **步骤 3：实现 UserDefaults 存储和视图模型**

`UsageStore` 只保存编码后的 `UsageSnapshot` 和抓取时间。`UsageViewModel.start()` 执行首次连接、立即读取、启动 60 秒 `ContinuousClock` 循环并消费更新流。`refresh()` 成功后写缓存；失败且有缓存时进入 `.stale`，无缓存时进入 `.unavailable`。

重连延迟固定为 `[1, 2, 4, 8, 16, 32, 60]` 秒，后续保持 60 秒；任意成功连接后重置为 1 秒。取消 `startTask` 时必须同时停止客户端子进程。

        .deletingLastPathComponent()
        .deletingLastPathComponent()
    let data = try Data(contentsOf: projectRoot.appending(path: "Resources/Info.plist"))
    let plist = try PropertyListSerialization.propertyList(from: data, format: nil) as! [String: Any]
    XCTAssertEqual(plist["CFBundleIdentifier"] as? String, "local.codexbar.app")
    XCTAssertEqual(plist["LSUIElement"] as? Bool, true)
    XCTAssertEqual(plist["LSMinimumSystemVersion"] as? String, "14.0")
}

- [ ] **步骤 3：创建应用元数据与构建脚本**

`Info.plist` 必须包含 `CFBundleExecutable=CodexBar`、`CFBundleIdentifier=local.codexbar.app`、`CFBundleName=CodexBar`、`CFBundleVersion=1`、`CFBundleShortVersionString=0.1.0`、`LSUIElement=true` 和 `LSMinimumSystemVersion=14.0`。

构建脚本执行：

```bash
swift build -c release
app_dir=".build/app/CodexBar.app"
mkdir -p "$app_dir/Contents/MacOS"
cp .build/release/CodexBar "$app_dir/Contents/MacOS/CodexBar"
cp Resources/Info.plist "$app_dir/Contents/Info.plist"
codesign --force --deep --sign - "$app_dir"
codesign --verify --deep --strict "$app_dir"
```
